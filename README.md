# CCTV-Academy-Pro

آکادمی آموزشی فارسی شبکه و CCTV؛ یک وب‌سایت ایستا و راست‌به‌چپ که محتوای آن در `index.html` قرار دارد.

## اجرا

- فایل `index.html` را مستقیماً در مرورگر باز کنید.
- برای اجرای محلی با یک سرور ساده، در ریشه مخزن اجرا کنید:

```sh
python3 -m http.server 8000
```

سپس نشانی `http://localhost:8000` را باز کنید. برنامه برای نمایش محتوای اصلی به سرور یا سرویس API وابسته نیست.

## ساختار فعلی

- `index.html`: رابط کاربری، سبک‌ها، محتوای فصل‌ها و پیوست‌ها، تمرین‌ها و اسکریپت‌های داخلی.
- `docs/audit/`: استانداردها و مستندات ممیزی و تحویل.
- `tests/`: آزمون‌های ایستای قابل اجرا با Node.js.

پیشرفت کاربر در مرورگر و با `localStorage` نگهداری می‌شود. پاک‌کردن داده‌های مرورگر می‌تواند این پیشرفت را حذف کند؛ پیش از هر پاک‌سازی از داده‌های مهم محافظت کنید.

## آزمون

نیازمندی: Node.js نسخه ۱۸ یا جدیدتر.

```sh
node tests/static-audit.mjs
```

این آزمون ساختار پایه HTML را بررسی می‌کند: تعداد موضوعات، شناسه‌های تکراری، مقصد پیوندهای داخلی، وجود تمرین‌ها و ساختار گزینه‌های چهارگزینه‌ای. این آزمون جایگزین آزمون تعاملی در مرورگر، بررسی دسترس‌پذیری یا بازبینی صحت علمی محتوا نیست.

## نگهداری محتوا

- پیش از تغییر، شاخه و آخرین commit شاخه `main` را بررسی کنید.
- محتوای موجود، شناسه‌های موضوعات، کلیدهای `localStorage` و سازگاری لینک‌های داخلی را حفظ کنید.
- موضوع جدید باید شناسه یکتا، پیوند ناوبری و مقصد معتبر داشته باشد.
- تغییرات را در شاخه مستقل انجام دهید؛ فقط پس از اجرای آزمون‌ها و بازبینی، PR بسازید.
- تعدادهای نمایشی را از ساختار واقعی صفحه محاسبه کنید؛ عدد ثابت و تکراری وارد نکنید.

## انتشار

مخزن برای میزبانی ایستا مناسب است. تنظیمات واقعی GitHub Pages را از بخش **Settings → Pages** مخزن بررسی کنید؛ وجود فایل HTML به‌تنهایی فعال‌بودن Pages را اثبات نمی‌کند.

## مستندات ممیزی

روش ممیزی، ثبت شواهد، شدت‌یابی یافته‌ها و تحویل کار در [استاندارد ممیزی و تحویل](docs/audit/AUDIT-AND-HANDOFF-STANDARD.md) تعریف شده است.
